# 🖨️ ShadowLabs 3D

**Мастерская 3D-печати** — каталог товаров, мини-игры и достижения прямо в браузере.

🌐 **Живой сайт:** [zxcrixd.github.io/shadowlabs3d](https://zxcrixd.github.io/shadowlabs3d)

---

## ✨ Что умеет

- 🛍️ **Каталог товаров** — 65 позиций, категории, поиск
- 🛒 **Корзина и избранное** — сохранение в браузере
- 🔵 **Вход через Google** — через Firebase Authentication
- 💳 **Оплата** — виджет DonatePay с расчётом комиссии
- 🎮 **4 мини-игры** — Memory, Колесо удачи, Реакция, ZombieSmasher
- 🏅 **12 достижений** — за заказы, игры и активность
- 🎨 **10 тем оформления** — Космос, Хэллоуин, Новый год, Лето, Киберпанк и др.
- 📱 **Работает везде** — телефон, планшет, ПК (адаптивный дизайн)
- 💚 **Раздел поддержки** — донаты автору

---

## 🚀 Технологии

- **HTML + CSS + JavaScript** — без фреймворков и сборки
- **Firebase Authentication** — вход через Google
- **Firebase Realtime Database** — облачное хранение товаров
- **GitHub Pages** — бесплатный хостинг
- **DonatePay** — приём платежей
- **localStorage** — корзина, избранное, пользователи
